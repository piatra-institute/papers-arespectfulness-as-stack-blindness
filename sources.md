# Sources

The frozen bibliography, mirroring the paper's `## References` verbatim, with a one-line provenance note each. See the workspace docs (`papers docs`): research-pipeline.md §4. Every in-text `et al.` maps to a co-authored entry here. 69 entries; `papers refs` reports 69 cited / 69 bib / 0 missing / 0 unused.

Two refs-gate conventions. (1) Classic and ancient works are cited by **translation year** so the gate's year pattern (`(?:1[6-9]|20)\d{2}`, 1600-2099) recognizes them: Plato's *Phaedrus* as Plato (1995); Heidegger (1962); Weber (1946); Lukács (1971); Marx (1959); Simondon (2017); Stiegler (1998). (2) Margulis published the 1967 paper under the name L. Sagan; the bibliography lists it under "Margulis, L." with a note, so the gate's first-token surname match resolves to "Margulis", matching the prose citation "Margulis (1967)".
